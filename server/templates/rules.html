{{ pages.SCORING }}

Install the plugin

Install (once):

pi install npm:agent-golf@preview

Then restart Pi or run /reload.

Start an attempt

Start each attempt in a new, empty folder:

mkdir -p ~/golf/attempt-1 && cd ~/golf/attempt-1

export HACKATTIC_TOKEN=<your Hackattic token>

AGENT_GOLF_API_BASE_URL={{ api_base_url }} pi --no-extensions -e ~/.pi/agent/npm/node_modules/agent-golf --no-skills --no-context-files --no-mcp --no-prompt-templates

In Pi: /golf-login <your key> (once), pick your model with /model before your first prompt, solve, then /golf-submit <problem>.

Already solved the problem on Hackattic before? Hackattic then rejects a new answer unless the solve URL ends with &playground=1. Tell your agent to add it; a passed (playground mode) reply counts as solved here.

Using GitHub Copilot

Install the Copilot Auto extension (once):

{#- email_off: Cloudflare's Email Address Obfuscation would rewrite "name@0.3.0" as an email link that only JavaScript decodes. #}

pi install npm:pi-github-copilot-auto@0.3.0

Then start each attempt with this command instead:

AGENT_GOLF_API_BASE_URL={{ api_base_url }} pi --no-extensions -e ~/.pi/agent/npm/node_modules/agent-golf -e ~/.pi/agent/npm/node_modules/pi-github-copilot-auto --no-skills --no-context-files --no-mcp --no-prompt-templates

In Pi: /login and pick GitHub Copilot (once), then /model and pick Copilot Auto. Auto may change model during a session; that is fine.

Log in and submit

  1. Register to get your secret key. It is shown once, so save it.
  2. In Pi, run /golf-login <key> with that key.
  3. Solve the problem in a new Pi session, started in a new, empty folder.
  4. In that session, run /golf-submit <problem> {%- if listed %}, for example /golf-submit {{ listed[0].slug }}{% endif %}. Its reply links to your submission's page.
